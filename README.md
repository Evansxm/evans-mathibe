# Evans Mathibe creative landing page

A responsive, static creative portfolio landing page for Evans Mathibe.

## Included

- Semantic HTML with responsive CSS and reduced-motion support
- SEO metadata, crawler-facing sitemap, robots file, and route manifest
- Accessible skip link, labels, focus states, and persistent WhatsApp/TikTok actions
- Downloadable `media-kit.pdf` creative package
- Contact form that opens the visitor's email app with a prepared message to `evans.mathibe@mail.com`
- Supplied Evans Mathibe artwork in `assets/evans-mathibe-mark.png`

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish

The project is intended for GitHub Pages. The `main` branch is configured to publish the repository root.
