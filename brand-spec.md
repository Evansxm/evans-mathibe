# Evans Mathibe brand specification

## Primary asset

`assets/evans-mathibe-mark.png` is the supplied Evans Mathibe visual identity artwork and is used as the hero brand image.

## Visual system

The page uses an oxblood foundation (`#27090c` / `#160507`), crimson red (`#8f1e28`), warm coral (`#ef7b80`), blush (`#f6c0ba`) and paper (`#f8e5dc`). Typography is a system sans stack for display hierarchy with Georgia as the expressive serif accent. The layout uses sharp editorial frames, clipped geometric fields and restrained motion.

## Contact destinations

Only the supplied email, phone, WhatsApp and TikTok destinations are used throughout the page.
